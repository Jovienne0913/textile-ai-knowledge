## 🛠 技术说明

- **纯CSS实现**，无JavaScript依赖，兼容企业微信内置浏览器
- 配色：深蓝(#1a365d) · 浅蓝(#3182ce) · 白(#fff) · 灰(#f7fafc)
- 响应式设计，支持手机端访问
- 支持按分类纯CSS筛选

## 📝 如何新增内容

编辑 `index.html`，在对应分类区域复制卡片模板并填入新内容：

```html
<div class="card 分类class">
  <div class="card-header">
    <span class="card-category cat-分类">分类名称</span>
    <h2 class="card-title">条目标题</h2>
    <span class="card-date">日期</span>
  </div>
  <div class="card-body">
    <h4>🔑 核心要点</h4>
    <ul>
      <li>要点内容</li>
    </ul>
  </div>
  <div class="card-source">
    来源：<a href="链接">来源名称</a>
  </div>
</div>
```

可用分类class：`report`、`case`、`tech`、`policy`
